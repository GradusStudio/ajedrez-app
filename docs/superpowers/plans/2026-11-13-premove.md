# Premove en cadena con tablero de plan — Plan de implementación

> **Para quien implemente con agentes:** REQUIRED SUB-SKILL: usar `superpowers:subagent-driven-development` (recomendado) o `superpowers:executing-plans` para ejecutar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`).

**Objetivo:** Permitir preparar jugadas en cadena mientras el bot piensa, sobre un tablero de plan, y ejecutarlas solas cuando el bot responda si siguen siendo legales.

**Arquitectura:** La lógica pura vive en `src/game/premove.ts` (turno cambiado, plan, recorte de cola y legalidad real). `GameScreen` guarda la cola y muestra el plan como FEN; `Board` solo agrega el resaltado de destinos, la cancelación con clic derecho o doble toque y un interruptor de sonido. La cola es la única fuente de verdad y se recorta en la primera jugada que deja de ser válida.

**Tecnología:** Expo, React Native, React Native Web, TypeScript, `chess.js`, `tsx` + `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-13-premove-design.md`

5. **El clic derecho o Escape abre el menú del navegador o afecta otras pantallas.** Debe evitarse solo en la partida y solo con jugadas preparadas; las lecciones y puzzles no deben cambiar. Verificación manual en las tareas 2 y 3.

```ts
export type TapPoint = { time: number; x: number; y: number };
export const DOUBLE_TAP_MS = 300;
export const DOUBLE_TAP_PX = 30;

export function isDoubleTap(previous: TapPoint | null, next: TapPoint): boolean {
  if (!previous) return false;
  return (
    next.time - previous.time <= DOUBLE_TAP_MS &&
    Math.hypot(next.x - previous.x, next.y - previous.y) <= DOUBLE_TAP_PX
  );
}
```

```ts
import { useEffect, type RefObject } from 'react';

/** Evita el menú del navegador y avisa con clic derecho o con Escape sobre el tablero. */
export function useContextMenu(ref: RefObject<unknown>, onContextMenu?: () => void): void {
  useEffect(() => {
    const node = ref.current as unknown as HTMLElement | null;
    if (!node || !onContextMenu) return;
    const menu = (e: MouseEvent) => {
      e.preventDefault();
      onContextMenu();
    };
    const key = (e: KeyboardEvent) => {
      if (e.key !== 'Escape') return;
      e.preventDefault();
      onContextMenu();
    };
    node.addEventListener('contextmenu', menu);
    document.addEventListener('keydown', key);
    return () => {
      node.removeEventListener('contextmenu', menu);
      document.removeEventListener('keydown', key);
    };
  }, [ref, onContextMenu]);
}
```
