# Premove en cadena con tablero de plan — Plan de implementación

> **Para quien implemente con agentes:** REQUIRED SUB-SKILL: usar `superpowers:subagent-driven-development` (recomendado) o `superpowers:executing-plans` para ejecutar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`).

**Objetivo:** Permitir preparar jugadas en cadena mientras el bot piensa, sobre un tablero de plan, y ejecutarlas solas cuando el bot responda si siguen siendo legales.

**Arquitectura:** La lógica pura vive en `src/game/premove.ts` (turno cambiado, plan, recorte de cola y legalidad real). `GameScreen` guarda la cola y muestra el plan como FEN; `Board` solo agrega el resaltado de destinos, la cancelación con clic derecho o doble toque y un interruptor de sonido. La cola es la única fuente de verdad y se recorta en la primera jugada que deja de ser válida.

**Tecnología:** Expo, React Native, React Native Web, TypeScript, `chess.js`, `tsx` + `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-13-premove-design.md`

1. **La cadena de la misma pieza no funciona.** El peón tiene que poder avanzar tres veces y coronar sobre el tablero de plan. Pruebas de `planPremoveFen` en la tarea 1.

```ts
import { Chess, type Square } from 'chess.js';

export type PremovePiece = 'q' | 'r' | 'b' | 'n';
export type Premove = { from: Square; to: Square; promotion?: PremovePiece };

export function passTurn(fen: string): string
export function planPremoveFen(realFen: string, premoves: Premove[]): string | null
export function clipPremoves(realFen: string, premoves: Premove[]): Premove[]
export function resolvePremove(fen: string, premove: Premove): Premove | null
```

Implementación:
- `passTurn`: separar el FEN por espacios. Si tiene menos de 4 partes, devolverlo igual. Cambiar `parts[1]` entre `w` y `b`, poner `parts[3] = '-'` y volver a unir.
- Un auxiliar privado `applyPlanMove(fen, premove)` crea `new Chess(fen)`, hace `chess.move({ from, to, promotion })` y devuelve `passTurn(chess.fen())`; si tira, devuelve `null`.
- `planPremoveFen`: empezar en `passTurn(realFen)` y aplicar cada premove con `applyPlanMove`; si alguna devuelve `null`, devolver `null`. Al final, devolver el FEN.
- `clipPremoves`: empezar en `passTurn(realFen)`, aplicar en orden y devolver `premoves.slice(0, i)` en la primera que falle. Si todas pasan, devolver `premoves`.
- `resolvePremove`: crear `new Chess(fen)`, intentar la jugada y devolver el mismo objeto `premove`; si tira, devolver `null`.

- [ ] **Paso 3: Implementar `src/components/boardTap.ts`**

```ts
export type TapPoint = { time: number; x: number; y: number };
export const DOUBLE_TAP_MS = 300;
export const DOUBLE_TAP_PX = 30;

export function isDoubleTap(previous: TapPoint | null, next: TapPoint): boolean {
  if (!previous) return false;
  return (
    next.time - previous.time <= DOUBLE_TAP_MS &&
    Math.hypot(next.x - previous.x, next.y - previous.y) <= DOUBLE_TAP_PX
  );
}
```

```ts
import { useEffect, type RefObject } from 'react';

/** Evita el menú del navegador y avisa cuando se hace clic derecho sobre el tablero. */
export function useContextMenu(ref: RefObject<unknown>, onContextMenu?: () => void): void {
  useEffect(() => {
    const node = ref.current as unknown as HTMLElement | null;
    if (!node || !onContextMenu) return;
    const handler = (e: MouseEvent) => {
      e.preventDefault();
      onContextMenu();
    };
    node.addEventListener('contextmenu', handler);
    return () => node.removeEventListener('contextmenu', handler);
  }, [ref, onContextMenu]);
}
```
